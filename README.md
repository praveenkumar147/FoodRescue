# FoodRescue: Surplus Food Donation Management Platform

## Stack
Flask, MySQL, HTML, CSS, Bootstrap, Python

## Run steps
1. Extract this folder and open it in Antigravity.
2. Open terminal inside the folder.
3. Run: `python -m venv venv`
4. Windows activate: `venv\Scripts\activate`
5. Install: `pip install -r requirements.txt`
6. Open MySQL and run the full `database.sql` file.
7. If MySQL has password, edit `config.py`.
8. Run: `python app.py`
9. Open: `http://127.0.0.1:5000`
